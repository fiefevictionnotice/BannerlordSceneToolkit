# Scene Toolkit docs

Everything about the Bannerlord Scene Toolkit itself. Other material (general mapping
advice, community guides) is under [Miscellaneous docs](../misc/README.md).

**Want to search everything at once, or ask an AI about the toolkit?** Download
[SCENE-TOOLKIT-DOCS-ALL-IN-ONE.md](SCENE-TOOLKIT-DOCS-ALL-IN-ONE.md). It holds every file
below in one Markdown file (install guide, in-editor docs, troubleshooting, known issues,
roadmap, tutorial transcript, changelog), so Ctrl+F finds anything and an AI chat can take
it as a single upload. On GitHub, open it and use the download button (Download raw file).

## In-editor documentation

The same text as the toolkit's **Documentation** buttons, exported from the code on every
sync, so it always matches the source:

- [in-editor/USER-GUIDE.md](in-editor/USER-GUIDE.md) - the User Guide (every Documentation button)
- [in-editor/TECHNICAL-DOCS.md](in-editor/TECHNICAL-DOCS.md) - the Technical Docs (F9)
