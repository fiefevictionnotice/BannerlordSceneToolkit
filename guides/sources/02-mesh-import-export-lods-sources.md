# Sources: Getting Meshes from Blender/Max into the Bannerlord Editor: Export, Import, Naming, LODs

The community findings behind [Getting Meshes from Blender/Max into the Bannerlord Editor: Export, Import, Naming, LODs](../02-mesh-import-export-lods.md), as mined from the Discord export, with a jump link to the message for each one.

- **Access:** links open in Discord and only work for members of the Mount & Blade Modding server. Deleted messages and departed users won't resolve.
- **Where links land:** each link points to the best-matching message by the credited author on that date. That is usually the statement itself, sometimes the question or reply next to it, so read the surrounding thread.
- **Paraphrase:** claim text is paraphrased. The credited people are the source; the wording is ours.

190 of 192 findings have a message link.

### MESH-IO (#bl-3d-art)

- **Set import "unit size" to `m` in the Resource Browser** . Otherwise meshes arrive 100x too large, floating or hovering above the character. AverageAlien suggested cm when the Blender scene is already scaled to the extracted body.<br>ThrashManiac9/nwetta/Ayden, 2020-10-09 to 10-22 · confirmed (mm export came in huge, per KageBlink 2020-10-24) · [ThrashManiac9, 2020-10-09](https://discord.com/channels/411286129317249035/697071240015380500/764215980237783090)
- **Blender FBX export for rigged meshes** : disable "Add Leaf Bones" (Armature section), which Blender re-enables by default each session. Leaf bones make a helmet hang behind the head or animate without sticking to the skeleton. With "Selected Objects" ticked you must select the mesh and skeleton, or you export a ~4 KB empty file.<br>ThrashManiac9/PlebeianKilo/Apalmemnom, 2020-10-09 to 10-15 · confirmed · [PlebeianKilo [ER], 2020-10-09](https://discord.com/channels/411286129317249035/697071240015380500/763996761408405505)
- **Import via Resource Browser, not by hand-copying** : right-click Assets, then Import. The game copies files into AssetSources, and you edit those copies afterwards. Native module is read-only. Reimporting a mesh with the same name needs the old one deleted first.<br>gkx 2020-10-07, AverageAlien 2020-10-08, ThrashManiac9 2020-10-14 · confirmed · [gkx, 2020-10-07](https://discord.com/channels/411286129317249035/697071240015380500/763489438437212182)
- **Mesh name = Blender object name** . A helmet kept the name "sphere" and another import became "cylinder" because the Blender objects weren't renamed. The XML `mesh=` must match the name in the Resource Browser exactly.<br>Enclave 2020-10-23, zgmrvn 2020-10-14 · confirmed · [zgmrvn, 2020-10-14](https://discord.com/channels/411286129317249035/697071240015380500/765997835463557211)
- **A missing or misnamed mesh is silently invisible** (a trick for invisible helmets). If a mesh shows in the tools but not in game, either the name is misspelled or the material isn't visible in game.<br>PlebeianKilo, 2020-10-10/13 · confirmed · [PlebeianKilo [ER], 2020-10-13](https://discord.com/channels/411286129317249035/697071240015380500/765726679896948757)
- **LOD naming** : put LODs in the same FBX as separate objects named `name.lod1`, `name.lod2` and so on. The "auto LOD" button only previews LOD switching as you zoom. TW's LOD generator is a paid in-house tool and is not shared.<br>Zeyria/Doctard/gkx, 2020-10-02 and 10-10 · confirmed (dev for no generator) · [gkx, 2020-10-02](https://discord.com/channels/411286129317249035/697071240015380500/761577389041516556)
- **LOD materials** : you shouldn't need different materials for LOD meshes. The importer matches materials by name from the FBX, so name Blender materials after the intended editor materials to avoid hand-assigning five LODs.<br>gkx 2020-10-13, PlebeianKilo 2020-10-13 · confirmed (dev) · [gkx, 2020-10-13](https://discord.com/channels/411286129317249035/697071240015380500/765667625111257109)
- **Deleting or importing assets in bulk is slow** : importing 40 models at once or deleting all assets at once lags badly, so do them one at a time.<br>PlebeianKilo, 2020-10-13 · single-report · [PlebeianKilo [ER], 2020-10-13](https://discord.com/channels/411286129317249035/697071240015380500/765634636763234325)
- **A duplicate folder inside a module with identical tpac names broke assets** until it was removed.<br>PlebeianKilo, 2020-10-20 · single-report · [PlebeianKilo [ER], 2020-10-20](https://discord.com/channels/411286129317249035/697071240015380500/768213898423566338)
- **DAE round-trip may darken textures** : re-exporting a vanilla mesh from Blender (imported as .dae, re-imported as .fbx) darkened it. An OBJ round-trip did not.<br>order_without_power, 2020-10-24 · single-report · [order_without_power, 2020-10-24](https://discord.com/channels/411286129317249035/697071240015380500/769631058186207243)
- **Orientation** : the community-ripped male body in the pin is rotated 180 degrees relative to TpacTool exports. TpacTool-exported skeletons were also reported as wrongly oriented, which explains many odd imports.<br>npc99 2020-06-28, kiet 2020-10-16 (hearsay) · confirmed (body), single-report (skeleton) · [npc99., 2020-06-28](https://discord.com/channels/411286129317249035/697071240015380500/726948858461945896)
- **Game scale is 100x smaller than Blender default: import with "convert to unit = m" (not "mm"), or scale the skeleton/mesh by 100.** Wrong unit gives a giant or tiny model, invisible armor, or a helmet floating above the head.<br>Apalmemnom/nwetta 2020-10-25, 2020-11-02; ThrashManiac9 2020-12-03; abrookes 2020-11-17 · confirmed · [nwetta, 2020-11-02](https://discord.com/channels/411286129317249035/697071240015380500/772903845054644235)
- **LOD naming:** put LODs in the same FBX as `MESH`, `MESH.lod1` ... `MESH.lod5` (people also wrote `_lod1`; `body_male_a_lod0` replaces that body piece). For variations the base name AND every LOD must be renamed, otherwise a "failed to import mesh with same name" error corrupts LODs.<br>Deleted User/Lord Eastwood 2020-11-08; DG 2020-11-05; anonymous 2020-12-09 · single-report/mixed · [Deleted User, 2020-12-09](https://discord.com/channels/411286129317249035/697071240015380500/786264306655821825)
- **Make LODs after rigging works; duplicate only the mesh (not the skeleton), or Alt+P clear parent keep transform and delete the extra skeleton, then Ctrl+P again.** Auto-decimate degrades silhouettes; manual edge-loop dissolving keeps UVs best. Check LODs by dragging into the scene editor and moving the camera.<br>John_M 2020-11-16/17; PlebeianKilo 2020-12-02 · confirmed · [John_M, 2020-11-16](https://discord.com/channels/411286129317249035/697071240015380500/777904529517576234)
- **LOD triangle goal = LOD0 triangle count times a percentage (75/50/25 ...); you can stop at a tiny count and reuse it.** LOD1 starts at about 100 px wide on a 1440p screen, so even bad LOD1s are rarely noticed; the meta mesh editor shows the LOD distances.<br>John_M/OokamiJamie 2020-11-16; Kaffegörare 2020-11-07 · confirmed · [John_M, 2020-11-16](https://discord.com/channels/411286129317249035/697071240015380500/777923535921217597)
- **Meshes with a LOD1 that replaces LOD0 in-game despite looking right in the editor were fixed by rebuilding the module and reimporting everything.**<br>Kaffegörare 2020-11-07 · single-report · [Kaffegörare, 2020-11-07](https://discord.com/channels/411286129317249035/697071240015380500/774685323023220745)
- **TpacTool: export rigged meshes as DAE (bug resets format to OBJ on the final save screen).** But DAE contains doubled vertices and no tri-strips; blocky/split normals appear in Blender and need merge-by-distance, or export OBJ and lose rigging.<br>npc99 2020-10-30; order_without_power/Jester's Ego 2020-11-19, 2020-12-01 · confirmed · [npc99., 2020-10-30](https://discord.com/channels/411286129317249035/697071240015380500/771684285177659393)
- **One mesh for several item variants is not possible by XML: import the mesh several times under different names.**<br>PlebeianKilo 2020-11-24/25 · confirmed · [PlebeianKilo [ER], 2020-11-24](https://discord.com/channels/411286129317249035/697071240015380500/781016819116408843)
- **FBX export: select only the meshes (and skeleton) you want, disable "Add Leaf Bones," remove stray animations/camera, and use Apply Scalings FBX All.** Leaf bones cause garbled/blocky skinning; mesh facing backwards can come from the Y-up export default.<br>ThrashManiac9 2020-10-29, 2020-12-08; OokamiJamie 2020-11-16; Servius 2020-11-18 · confirmed · [ThrashManiac9, 2020-10-29](https://discord.com/channels/411286129317249035/697071240015380500/771386502574768139)
- **Overlapping UVs and many UV shells are not a performance issue** (one developer-aware view); 4K textures are discouraged in favor of tiling.<br>jacobins/koya 2020-10-31; SnotFlower 2020-11-04 · single-report · [jacobins, 2020-10-31](https://discord.com/channels/411286129317249035/697071240015380500/772140720886120459)
- **Packaging a mod: the editor's Publish step creates AssetPackages (shareable); `EmAssetPackages` belongs to editor use.** Leftover unpackaged assets can still make a published module crash.<br>John_M 2020-11-09 · confirmed · [John_M, 2020-11-09](https://discord.com/channels/411286129317249035/697071240015380500/775399877382766592)
- **Mesh name in the XML must match the mesh name inside the FBX** (lowercase, exact). Invisible items are often mesh-name or XML typo issues, and a single missing `/` can hide an item entirely.<br>Hayster, Jester's Ego, Corv0, 2020-12-21, 2021-01-06, 2021-02-10 · confirmed · [Jester's Ego, 2020-12-21](https://discord.com/channels/411286129317249035/697071240015380500/790505793426030612)

The male base is 178 cm and Blender units map 1:1.<br>Dawa, Not A Box, Isaac, 2021-01-16, 2021-02-22, 2021-02-27 · confirmed · [Not A Box, 2021-01-16](https://discord.com/channels/411286129317249035/697071240015380500/800018845695475733)
