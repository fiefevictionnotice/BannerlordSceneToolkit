# Sources: Bannerlord 3D Troubleshooting and Tools

The community findings behind [Bannerlord 3D Troubleshooting and Tools](../07-troubleshooting-and-tools.md), as mined from the Discord export, with a jump link to the message for each one.

- **Access:** links open in Discord and only work for members of the Mount & Blade Modding server. Deleted messages and departed users won't resolve.
- **Where links land:** each link points to the best-matching message by the credited author on that date. That is usually the statement itself, sometimes the question or reply next to it, so read the surrounding thread.
- **Paraphrase:** claim text is paraphrased. The credited people are the source; the wording is ours.

190 of 190 findings have a message link.

### TOOLS (#bl-3d-art)

- **TpacTool usage** : needs .NET Framework 4.6.2. It only reads tpac files (no gtex textures, so about half of textures are missing). The 2020-04 exe breaks on newer game builds, so use a rebuilt/0.2.0 release matching your game version (1.5.x). Default export is OBJ (static); pick DAE to get rigged skeleton plus mesh. Skeleton can't be exported alone.<br>npc99/order_without_power/Bogheim, 2020-07-19 to 10-24 · confirmed · [npc99., 2020-07-19](https://discord.com/channels/411286129317249035/697071240015380500/734450062771486841)
- **Module layout and launch** : the module folder needs `AssetPackages`, `Assets`, `AssetSources`, `EmAssetPackages`. SubModule.xml `Id` must match the folder name. Create modules through the editor. To run with the modding kit, rename the shipping client exe `Win64_Shipping_Client` to `Win64_Shipping_wEditor`.<br>John_M/Kepons/CF2lter/ThrashManiac9, 2020-10-01 to 10-14 · single-report each · [CF2lter, 2020-10-02](https://discord.com/channels/411286129317249035/697071240015380500/761566185853812736)
- **Documentation sources** : John_M's "Bannerlord 3D Asset Workflow" doc and KingOfTheN0RTH's "Armor Tutorial" doc became the de-facto guides. The official docs.modding.bannerlord.com material editor page lists the channel layout.<br>John_M 2020-10-02, KingOfTheN0RTH 2020-10-20 · confirmed · [John_M, 2020-10-01](https://discord.com/channels/411286129317249035/697071240015380500/761279315765362738)
